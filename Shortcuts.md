# Shortcuts

Shared with every ProjectForge project and kept current by ProjectForge, so edits here are overwritten: change these in ProjectForge's meta doc. This project's own shortcuts are under SHORTCUTS in spotify_graph.md, and win on a clash.

When a message is a shortcut, or starts with one, do what it says.

- N,N,N (e.g. 3,3,3, or 5,0,2) — look at the project as it is now (the app,
  the code, the spec), then list N things to cut, N to add and N to improve, in
  that order; 0 skips a list. Rank each list by impact, give each item a line on
  why and what it rests on, and build nothing until I pick.
